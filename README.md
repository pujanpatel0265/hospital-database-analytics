# Hospital Database Analytics

## Project Overview
This project designs and implements a hospital database system using SQL Server. The project includes database schema design, ERD diagrams, SQL queries, role-based security, and a Power BI dashboard preview.

The main goal of this project is to manage and analyse hospital operations such as patients, doctors, appointments, billing, prescriptions, rooms, departments, and staff.

## Tools and Technologies
- SQL Server
- T-SQL
- Power BI
- Mermaid ERD
- Database Design
- Business Intelligence
- Role-Based Security

## Key Features
- Designed a normalized relational database for a hospital system
- Created 11 database tables with primary keys, foreign keys, unique constraints, and check constraints
- Inserted synthetic sample data for patients, doctors, appointments, billing, rooms, medicines, and staff
- Wrote 15 business queries for hospital analytics
- Created ERD diagrams for conceptual, logical, and physical design
- Added role-based database users and permissions
- Built a Power BI dashboard preview for business insights
